# mobility rules

This page lists the rules the suma platform enforces for mobility: the scooter and bike map, starting and ending trips, how trips are priced and charged, how trips are imported from Lime and Lyft, and how vendor services and rates are set up in the admin app. Each row says what the rule is, what you or a member would see when it applies, and where to fix it. "No admin fix - needs engineer" means the code shows no admin page for it. The last column points engineers to the exact code.

## Rules
