# members rules

This page covers member accounts: how people sign up and sign in with a phone code, what "verified" and "read-only" mean, what closing an account does, how staff roles control what you can see and change in the admin app, and how message preferences work. It lists the rules the software enforces, what you or a member will see when a rule is hit, and where to fix it in the admin app. Every rule below was taken from the code at the file and line shown. "No admin fix - needs engineer" means the code shows no admin screen that changes the behavior.

Words used on this page: "verified" means the member's identity has been confirmed (the "onboarding verified" switch on the member's admin page). "Read-only" means the member can sign in and look around but cannot buy or use services. A "sign-in code" is the 6-digit code texted or called to the member's phone. A "closed" account is one staff have closed (engineers call this "soft-deleted"). A "role" is a label on a member that grants admin permissions or program access.
