# checkout rules

This page covers carts and checkout: what happens from the moment a member adds a product to their cart in an offering, through starting checkout, choosing pickup or delivery and a payment method, and pressing the final button that places the order. It lists the rules the software enforces, what you or a member will see when a rule is hit, and where to fix it in the admin app. Every rule below was taken from the code at the file and line shown. "No admin fix - needs engineer" means the code shows no admin screen that changes the behavior. There is no admin screen for carts or unfinished checkouts; staff can only see a checkout once it has become an order.

Words used on this page: a "listing" is a product's entry and price inside one offering (an "offering product" in admin). A "started checkout" is a checkout the member has opened but not finished. A "payment method" is a card or bank account saved on the member's account.
