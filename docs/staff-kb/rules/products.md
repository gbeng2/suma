# products rules

This page lists the rules the suma system enforces around products: the product record itself (name, image, vendor, category), its inventory settings, and "offering products" (a product listed in one offering at a set price). Each row says what the rule is, what you or a member would see when it trips, and where to fix it in the admin app. Every row was taken from code that was read; the last column says where. "Offering product" means one product listed in one offering with a customer price and an undiscounted price.
