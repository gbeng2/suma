# eligibility rules

Eligibility is how suma decides which members get which programs and which payment triggers (automatic subsidies). It has three parts. An **attribute** is a label such as an organization name or "senior". An **assignment** gives an attribute to one member, one organization, or one role. A **requirement** is a formula built from attributes ("A AND B", "A OR NOT C") that is attached to programs and payment triggers. A member gets a program or trigger when it is inside its dates and the member passes at least one of its requirements. Offerings, private vendor accounts (Lime, Lyft Pass), and mobility pricing all hang off programs, so an eligibility mistake can hide food, bikes, and subsidies from members. This page lists the rules the software enforces, what you or a member will see when a rule is hit, and where to fix it in the admin app. Every rule below was taken from the code at the file and line shown.
