# orders rules

An order is created when a member finishes checkout in an offering. Every order carries two separate statuses: an **order status** (open, completed, or canceled) and a **fulfillment status** (unfulfilled, fulfilling, or fulfilled). The admin order page shows them together as "order status / fulfillment status" and offers buttons for the status changes that are currently allowed. This page lists the rules the software enforces for orders, what you or a member will see when a rule is hit, and where to fix it in the admin app. Every rule below was taken from the code at the file and line shown. "No admin fix - needs engineer" means the code shows no admin screen that changes the behavior.
