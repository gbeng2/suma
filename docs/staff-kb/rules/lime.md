# lime rules

This page follows a member's Lime journey from start to finish: linking a private Lime account, riding, how Lime's trip report emails become trips in suma, how those trips are charged, what happens with Lime violation emails, and how Lime access is taken away. suma's link to Lime works through a "private account": suma gives the member a stand-in email address, Lime emails a sign-in link to it, and suma passes the link on to the member. The member then rides in Lime's own app, and suma learns about the rides later from a report Lime emails to suma. Each row says what the rule is, what you or a member would see, and where to fix it. "No admin fix - needs engineer" means the code shows no admin page for it. The last column points engineers to the exact code.
