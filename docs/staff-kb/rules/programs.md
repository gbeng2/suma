# programs rules

A program is how suma decides who gets what. A program has a name, a description, an image, an open and close date, and a set of eligibility requirements. Offerings (food), vendor configurations (private accounts such as Lime or Lyft Pass), and mobility pricings (which rate a member pays for a bike or scooter service) are attached to programs. A member only sees those things when they are eligible for at least one attached program that is open right now. This page lists the rules the software enforces for programs, what you or a member will see when a rule is hit, and where to fix it in the admin app. Every rule below was taken from the code at the file and line shown.
