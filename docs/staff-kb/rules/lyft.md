# lyft rules

This page lists the rules the suma platform enforces for Lyft Pass (used for Lyft and Biketown rides). It follows the member's journey in order: setting up a Lyft Pass program, linking the member's private Lyft account, riding, importing the ride into suma ("trip sync"), charging, and removing the member from the pass. Members ride in the vendor's own app; suma invites them into a Lyft Pass program, and later reads the rides back from Lyft. Each row says what the rule is, what you or a member would see when it applies, and where to fix it. "No admin fix - needs engineer" means the code shows no admin page for it. The last column points engineers to the exact code. Rules that also appear on the mobility and vendors pages are collected under "Cross-area rules" so each rule is listed only once on this page.
