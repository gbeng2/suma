# offerings rules

An offering is a time-limited "shop" in the suma app (for example a farmers market box or a holiday meal). Each offering has a start and end time, a list of products with prices ("offering products"), pickup or delivery choices ("fulfillment options"), optional order limits, and one or more programs that decide which members can see it. This page lists the rules the software enforces for offerings, what you or a member will see when a rule is hit, and where to fix it in the admin app. Every rule below was taken from the code at the file and line shown. "No admin fix - needs engineer" means the code shows no admin screen that changes the behavior.
